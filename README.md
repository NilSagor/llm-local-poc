# LLM Local Inference PoC

A proof-of-concept evaluating whether local
LLM inference via Ollama is viable for 
on consumer hardware (RTX 4060, 8GB).

## Status
PoC -- disposable by design.  see `docs/` for hypothesis and verdict.

## Methodology
This PoC follows a 7 step process:

1. Define hypothesis + success metrics + scope
2. Research existing implementation
3. Test under realistic constraints
4. Record metrics, failures, bottlenecks
5. write 1-page go/revise/stop summary
7. Throw away or refactor
